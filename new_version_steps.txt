0) update CITATION.cff with version number and date
1) checkout main and merge in release branch (or just develop)
2) update version number with uv `uv version --bump <BUMP>` (BUMP is major, minor, patch, stable, alpha, beta, rc, post, dev)
3) commit version number change (`git add pyproject.toml uv.lock; git commit -m"Bump version to <newversion>"`)
4) tag new version in main branch (git tag -a v<newversion> -m <version message>) [the 'v' is important]
5) push main and tags to remote (git push origin main --tags)

If everything is setup on the CI (GitHub Actions) and PyPI, .github/workflows/release.yml should take care of the rest.
Check out example here:
https://docs.astral.sh/uv/guides/integration/github/#publishing-to-pypi
and here:
https://docs.pypi.org/trusted-publishers/adding-a-publisher/
